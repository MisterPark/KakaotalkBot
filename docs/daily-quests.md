# 일일 퀘스트

- `/퀘스트`, `/일퀘`: 본인의 오늘 진행도와 지급 보상을 조회합니다.
- 출석 성공 1회 10P, 일반 채팅 10회 10P, 상식퀴즈 정답자로 인정 3회 20P, 세 종류 완주 10P. 하루 추가 보상 최대 50P입니다.
- 기존 출석 10P와 퀴즈 난이도 보상은 별도 유지합니다. 보상은 완료 즉시 자동 지급합니다.
- 한국 시간 00시마다 새 날짜의 기록을 사용합니다. user_id 기준으로 방 간 진행도를 공유하며 닉네임과 무관합니다.
- 채팅은 사용자당 60초에 1회 인정하며 직전 인정 메시지와 앞뒤 공백을 제거한 내용이 같으면 제외합니다. 명령어, 빈 메시지, 시스템 이벤트, 봇 메시지, 개인 메시지를 제외합니다.
- 과거 메시지 소급 집계와 도입 전에 완료한 출석의 소급 지급은 하지 않습니다.
- `DB_DailyQuests`는 다음 프로그램 초기화에서 자동 생성합니다. `quest_key`는 한국 날짜와 user_id의 조합이며 `payload_json`에는 진행도, 마지막 인정 시각·내용의 SHA-256, 방별 로그 기준점, 퀘스트별 보상 금액·지급 시각·원본 방/로그 ID를 저장합니다. 메시지 본문은 저장하지 않습니다.
- 퀘스트별 고유 지급 키는 날짜:user_id:퀘스트 종류입니다. 사용자 잔액과 기록을 같은 Sheets 배치 요청으로 저장하며, 성공 확인 후 보상 알림을 보냅니다. 저장 실패 시 메모리의 변경 상태를 유지하여 다음 저장에 재시도합니다.
- 정상 종료·재시작은 저장된 진행도와 지급 기록을 이어 사용합니다. 저장에 실패한 상태에서 강제 종료하면 미저장 변경은 잃을 수 있습니다. 여러 봇 인스턴스가 같은 시트를 동시에 쓰는 운영은 지원하지 않습니다.
- 금액과 목표는 이번에 합의한 고정값이며, 퀘스트 종류는 매일 동일합니다.
