# 운영진 알림방

## 설정

1. 채팅 탭에서 감시할 방을 선택합니다.
2. **운영 → 운영진 알림방 → 방 목록 불러오기**를 누릅니다.
3. 감시 방과 같은 계정의 다른 방을 알림방으로 선택합니다. 운영진만 참여한 방인지 직접 확인하세요.
4. **운영진 알림 전송 사용**, 전송할 항목을 선택하고 **설정 저장**을 누릅니다.
5. 카카오톡에서 알림방을 열고 입력창을 비운 뒤 **테스트 알림 전송**을 누릅니다. 이 버튼은 실제 메시지를 전송합니다.

초기 상태는 전송 꺼짐입니다. 설정 저장 이후 수집한 기록부터 적용하며, 설정을 다시 저장하면 이전 대기·차단 항목은 취소합니다. 이미 전송한 메시지를 취소하거나 회수하지는 않습니다.

## 항목

- 재입장: 원본 방, 사용자 ID, 현재·이전 이름, 마지막 퇴장, 누적 퇴장·강퇴 횟수.
- 메모 등록: 원본 방, 대상 ID, 작성자. 메모 본문은 기본 제외합니다.
- 운영진의 `/이력 @사용자`: 기존 GUI 조회와 함께 알림방으로 결과를 보냅니다. 메모 본문은 별도 체크를 켰을 때만 포함합니다.
- 월간 집계: 포인트 초기화가 기록될 때 감시 중인 방의 지난달 통계와 두 랭킹을 보냅니다.
- 포인트 초기화 결과: 전 사용자 초기화가 DB에 저장된 뒤 적용 월과 사용자 수를 보냅니다.

긴 이력은 약 3,000자로 제한하며 전체 내용은 GUI에서 확인합니다. 메모 등록·재입장 알림은 DB 저장 성공 후 전송 대기열에 추가합니다. 알림방 메시지를 감시 방의 명령으로 처리하지 않습니다.

## 전송과 실패

기존 답변·멘션과 운영진 알림은 WindowsMacro의 공통 전송 대기열에서 직렬로 처리합니다. 알림은 선택 계정의 방 ID와 이름을 대조하고, 동명 방·잘못된 프로세스·작성 중인 입력을 발견하면 중단합니다. 방을 자동 검색해서 임의 선택하지 않으므로 알림방 창을 열어 두세요.

- **전송 전 차단**: 아직 입력하지 않았습니다. 창·계정·입력 상태를 해결하고 재시도 버튼을 누를 수 있습니다.
- **전송 입력 완료**: 전송 키를 한 번 전달하고 입력창이 비워진 것을 확인했습니다. 서버 수신을 보증하는 상태는 아닙니다.
- **결과 미확인**: 입력 시작 후 예외가 나거나 전송 중 앱이 종료되었습니다. 자동 재전송하지 않습니다. 실제 방에서 확인하세요. 부분 입력이 남을 수 있습니다.

전송 기록과 본문은 실행 파일 아래 `OperatorNotifications/outbox.json`에 보관합니다. 전송 직전에 시도 상태를 저장하므로 재시작 시 불명확한 메시지를 다시 보내지 않습니다. 파일이 손상되면 전송을 차단하며, 이를 삭제하면 중복 방지 이력이 사라지므로 임의 삭제하지 마세요.

카카오톡 입력 검증은 기존 멘션 기능과 동일한 검증된 버전에 의존합니다. 지원하지 않는 버전은 전송 전 차단합니다. 자동 GUI 전송과 사람의 동시 입력을 완벽히 분리할 수 없으므로 알림방 입력창은 비워 두세요.
