# 대법관 선거 명령

| 명령 | 동작 |
| --- | --- |
| `/선거설정 켜기` / `/선거설정 끄기` | 방의 선거 기능 활성화/중지 |
| `/선거시작` | 놓친 현재 회차 정기선거를 지금부터 3일간 진행 |
| `/보궐선거` | 기존 대법관을 유지하며 정원 10명 중 공석만 선출 |
| `/선거` / `/후보` | 현황과 후보·공약 확인 |
| `/출마 공약` / `/출마취소` | 출마와 사퇴 |
| `/투표 1 3` / `/투표취소` | 후보 번호로 승인투표 또는 철회 |
| `/선거결과` | 최근 회차의 후보별 득표·당선 여부 |
| `/선거기록` / `/선거기록 2` | 전체 또는 지정 회차의 정기·보궐선거 기록 |

선거 설정·개시는 방장용 관리 명령입니다. 최신 봇 계정·참여자 명부 확인이 필요하며, 진행 중인 본선이나 결선이 있으면 새 선거를 열지 않습니다. 같은 회차의 정기선거를 다시 열 수 없고, 공석은 보궐선거로 채웁니다.

정기선거는 한국 시간 홀수달 1일에 시작하고 3일간 투표합니다. 선출 정원 경계 동률은 24시간 결선으로 결정합니다. 수동 개시는 실제 명령 시점부터 3일이며, 이미 지나간 기간의 투표로 기록하지 않습니다. 예를 들어 2026년 11월 11일에 놓친 11월 선거를 열면 11월 14일 같은 시각에 본선을 마감하고, 다음 정기선거는 2027년 1월 1일, 임기 종료는 1월 4일 00시로 유지합니다.

보궐선거의 선출 수와 1인 최대 선택 수는 개시 시점의 공석 수입니다. 현직은 보궐선거에 출마할 수 없으며, 보궐 당선자는 해당 회차의 잔여 임기만 맡습니다. 투표·결선 기간이 다음 정기선거와 겹치면 수동 개시를 거부합니다.

회차 번호는 방별 개최 순서이며 정기·보궐선거를 모두 포함합니다. 선거기록에는 당시 후보 이름과 본선 득표, 결선 참가자의 결선 득표, 당선·미당선·사퇴 여부가 남습니다. 선거를 끄거나 대법관이 퇴장해도 과거 당선 기록은 유지됩니다. 긴 기록은 분할하며 각 긴 메시지의 제목 다음에 기존 접기 문자열을 넣습니다.

투표 기간에는 정기·보궐선거와 결선 모두 1시간마다 투표 참여 안내를 보냅니다. 새 선거 개시 또는 결선 전환 안내 후 1시간부터 시작하며, 마감 시각(한국 시간), 참여 인원, 후보 확인 및 투표 방법을 표시합니다. 후보가 없으면 출마 방법을 안내합니다. 긴 알림에도 제목 다음 접기와 비속어 필터가 적용됩니다.

다음 알림 시각은 선거 DB와 시트 백업에 함께 저장합니다. 재시작해도 같은 시간대 알림을 추가 생성하지 않으며, 오래 중지되었다가 다시 켜지면 최신 안내 한 건만 생성하고 이후 1시간 간격으로 진행합니다. 이미 진행 중인 구버전 선거도 적용됩니다. 선거 마감·결선 전환·기능 끄기 때 이전 투표 알림을 제거하며 전송 대기 중에도 현재 선거 상태를 다시 확인합니다. 채팅창이 닫혀 있으면 알림을 보존하고 방을 먼저 엽니다.
