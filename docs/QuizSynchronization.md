# 퀴즈 메모리 및 시트 동기화

- 퀴즈 호출·정답 판정·분류 목록은 프로세스 메모리만 사용합니다.
- 등록·삭제는 권한 검사 후 메모리에 즉시 반영합니다. 이 경로에는 Google Sheets 요청이 없습니다.
- 기존 약 60초 주기의 콘텐츠 갱신에서 미저장 변경의 복사본을 시트에 반영하고, 시트에서 직접 추가·수정한 문제도 읽어옵니다.
- 같은 분류와 문제 문장이 이미 시트에 있으면 추가하지 않고 시트의 최신 내용을 사용합니다. 대소문자는 구분하고 앞뒤 공백은 제외합니다.
- 삭제는 예약할 때의 원문과 같은 문제에만 반영합니다. 예약 후 시트에서 내용이 수정됐다면 그 문제는 보존하여 최신 목록으로 가져옵니다.
- 진행 중인 퀴즈의 정답이 갱신으로 바뀌지 않도록 시트에서 읽은 목록은 퀴즈 종료 후 교체합니다. 로컬에서 해당 문제를 삭제하면 즉시 종료합니다.
- 저장되지 않은 변경은 실행 파일 아래 `Data/QuizChanges-<시트ID>.json`에 원자적으로 기록합니다. 통신 실패·재시작 후 복구하며, 서버 응답 유실 시 다음 주기에 실제 값과 비교하여 중복 추가를 방지합니다.
- 통신 작업에는 변경 복사본만 전달합니다. 통신 중 새로 들어온 변경은 완료 처리에서 지우지 않습니다.
- 문제 시트 전체를 덮어쓰지 않고 필요한 행 삭제·추가만 한 번의 배치 요청으로 반영합니다. 시트의 직접 정렬·행 편집과 배치 적용 사이의 동시 변경은 원자적으로 잠글 수 없으므로 동기화 순간의 직접 정렬은 피해야 합니다.
- 저장 성공 전 PC를 옮겨야 한다면 위 미저장 기록도 함께 이동해야 합니다. 기록은 로컬 운영 데이터로 Git에 넣지 않습니다.

기존 사용자 정보·포인트·경험치는 기존대로 메모리에서 처리하고 주기 저장합니다. 이 변경은 퀴즈 관리의 즉시 시트 쓰기 경로를 같은 방식으로 맞춥니다.

## 출제 횟수 균등화

- 상식퀴즈 시트 G열 `출제횟수`를 주기 동기화에서 자동 추가합니다. 기존 빈 값은 0회입니다.
- 전체 또는 요청한 분류 안에서 최소 횟수인 후보를 한 번 순회하여 추리고, 후보 중 무작위로 선택합니다. 새 출제 시작 시 1회 증가하며 진행 중인 문제 재표시는 증가하지 않습니다.
- 출제 경로에는 네트워크 요청이 없습니다. 미저장 횟수는 기존 로컬 변경 기록으로 복구하고 약 60초 주기에 시트로 저장합니다.
- 횟수 저장은 G열만 수정합니다. 시트의 본문 수정은 유지하며, 시트에서 삭제한 문제를 횟수 저장 때문에 되살리지 않습니다.
- 횟수는 방별이 아닌 문제별 누적값입니다. 한 시트에 봇 프로세스 하나가 쓰는 운영을 기준으로 하며, 여러 PC의 동시 출제 횟수를 합산하는 구조는 아닙니다.
