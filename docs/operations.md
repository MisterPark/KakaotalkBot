# 운영 기능

## 사용

- 채팅 탭에서 방을 선택한 뒤 **운영** 탭에서 이름·ID 검색, 이력 조회, 메모 추가, 재입장 알림 확인, 월별 통계 조회를 합니다.
- GUI 메모 작성자는 **로컬 운영자**로 기록합니다. 이 PC의 봇 관리자를 신뢰하며, 특정 카카오 사용자 ID로 가장하지 않습니다.
- `/이력 @유저`: 방장·부방장만 사용. 해당 사용자의 이력을 봇 운영 화면에 엽니다. 방에 이력 내용을 공개하지 않습니다.
- `/메모 @유저 내용`: 방장·부방장만 사용. 작성자 ID·방·대상·시각과 메모를 보관합니다. 명령 자체는 채팅방에 입력한 메시지이므로 비공개 메모는 GUI에서 작성하세요.
- `/통계 [YYYY-MM]`: 일반 채팅 수, 활동 사용자 수, 입퇴장·강퇴 횟수, 마지막 확인된 참여자 수.
- `/채팅랭킹 [YYYY-MM]`, `/월간랭킹 [YYYY-MM]`: 기존 누적 채팅 랭킹을 방별 월간 일반 채팅 수 순위로 변경합니다.
- `/랭킹 [YYYY-MM]`: 기존 누적 인기도 랭킹을 방별 월간 좋아요−싫어요 순증감 순위로 변경합니다. 누적 인기도 자체는 보존합니다.
- 월 생략 시 한국 시간의 현재 월. 상위 20명, 동점 공동 순위, 동점 표시 순서는 ID순입니다.
- 강퇴 실행 기능과 `/강퇴` 분기는 제거했습니다.

## 기록 범위

도입 후 봇이 수집한 기록부터 집계합니다. 명령어·시스템 메시지·1:1 메시지와 봇 자신의 메시지는 채팅 순위에서 제외합니다. 과거 누적 기여도와 인기도를 특정 월로 추정해 옮기지 않습니다.

재입장은 같은 방·같은 ID의 이전 퇴장/강퇴 기록이 있는 입장으로 판단합니다. 방·입장 로그·사용자 ID로 알림을 저장해 재시작 중복을 방지합니다. GUI 알림 배지와 확인 상태를 제공하며 채팅방에 자동 공개하지 않습니다.

## 매월 포인트 초기화

- 한국 시간 매월 1일 00시부터 다음 타이머 처리 때 모든 사용자의 `Point`를 0으로 설정합니다. 경험치·레벨·누적 인기도·출석 이력은 유지합니다.
- 프로그램이 켜져 있으면 수신 중지 상태에서도 확인합니다. 프로그램이 꺼져 있으면 다음 실행 시 명령 처리보다 먼저 적용합니다. PC가 꺼져 있을 때 실제 자정 실행을 보장하는 외부 서비스는 아닙니다.
- 최초 도입 시 현재 월을 기준으로 등록하고 현재 포인트는 유지합니다.
- 초기화 전 사용자별 잔액과 처리 월을 보관합니다. 사용자 잔액과 처리 기록은 같은 Sheets 값 저장 요청에 포함됩니다. 저장 실패 시 봇 명령 처리를 중단하며, 재시도는 이미 메모리에서 초기화한 잔액을 다시 초기화하지 않습니다.
- 단일 봇 프로세스/단일 작성자를 전제로 합니다. 같은 시트를 여러 봇이 동시에 갱신하면 덮어쓰기를 방지할 수 없습니다.

## 저장

기존 사용자/입퇴장/닉네임/운영진 탭을 유지하고, 첫 정상 초기화 때 `DB_Operations` 탭을 자동 생성합니다. 종류·고유 키·JSON 원문의 세 컬럼으로 메모, 알림, 월간 집계, 초기화 기록을 저장합니다. 긴 ID는 JSON 문자열 셀 안에 저장하므로 Sheets의 숫자 정밀도 제한을 피합니다. 내용은 운영 GUI에서 조회합니다.
