# 방별 네임드 칭호

- `/네임드`: 현재 방 참여가 확인된 활성 칭호 보유자 전체 목록. 제목 뒤에 폭 없는 공백 500개를 넣어 채팅 접힘을 유도합니다.
- `/네임드지정 @유저 칭호 [30일]`: 현재 방 운영진만 사용. 실제 카카오톡 멘션이 필요합니다. 기간 생략 시 영구, 1~3650일, 칭호 1~30자.
- `/네임드해제 @유저 칭호`: 같은 방 운영진만 해제. 자동 칭호도 해제 가능하며 해당 월에 재생성하지 않습니다.
- `/조회`: 활성 칭호 표시. 운영 화면 이력에도 표시합니다.

DB_RoomTitles 탭을 다음 DB 초기화 때 자동 생성합니다. title_key와 payload_json에 방·사용자 ID, 칭호, 출처, 사유, 부여·만료·해제 시각과 지정/해제 운영진 ID를 저장합니다. ID는 채팅 본문에 출력하지 않습니다. 만료/해제 행을 삭제하지 않습니다.

매월 한국 시간 기준 전월 채팅 수와 인기도 순증감의 공동 3위 이내에 각각 월간 활동왕/월간 인기왕을 부여합니다. 양수 기록만 대상이며 동점으로 3명을 넘을 수 있습니다. 다음 달 1일 00시에 만료됩니다. 프로그램이 꺼져 있었다면 실행 시 현재 월 기준으로 부여합니다. 최초 도입 시에도 전월 집계가 있으면 적용합니다. 이전 월 집계가 없는 사용자에게는 자동 부여하지 않습니다.

포인트 보상이나 레벨 자동 칭호는 없습니다. 닉네임은 DB_RoomUsers의 방별 값을 사용합니다. 퇴장자의 칭호/이력은 유지하지만 현재 네임드 목록에는 표시하지 않습니다.
