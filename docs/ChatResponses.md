# 채팅 응답과 명령어 안내

`/명령어`와 `/?`는 시트의 안내를 읽되 퀴즈·문제 관리·대법관 선거·선거 설정 섹션은 `CommandHelp.cs`의 현재 사용법으로 갱신합니다. 그 밖의 사용자 정의 안내는 유지합니다. 시트에 도움말 행이 없어도 새 명령 안내를 표시합니다. 선거 강제 개시, 보궐선거, 회차별 선거기록과 퀴즈 번호 발급·전체 목록·번호 삭제를 함께 안내합니다.

모든 봇 응답은 전송 전에 사용자 ID 숨김, 비속어 마스킹, 긴 메시지 접기를 적용합니다. 명령 결과·시트 응답·뉴스·퀴즈·선거 자동 안내·입퇴장·운영진 알림 모두 같은 경로를 사용합니다. 제목 다음에 폭 없는 공백 500개를 넣는 기존 접기 형식을 유지합니다.

`ChatProfanityFilter.cs`의 한국어·영어 목록에 해당하는 표현을 `*`로 가립니다. 대소문자, 전각 영문, 단어 안에 들어간 공백·탭·문장부호·폭 없는 문자도 검사합니다. 서로 다른 줄은 이어 붙이지 않습니다. 일반 단어의 일부인 영문이나 시발점·시바견·새끼손가락·새끼줄 같은 정상 표현은 유지합니다. 목록 기반 필터이므로 새로운 은어는 해당 파일에 추가해야 합니다.

저장된 원본, 퀴즈 정답 판정, 닉네임 검색어 및 사용자 ID는 바꾸지 않습니다. 네이티브 멘션 본문과 실제 후보 라벨도 검사합니다. 멘션 이름에 비속어가 있으면 가린 이름을 넣은 일반 텍스트로 한 번 보내며, 이 경우 개인 멘션 알림은 발생하지 않습니다. 전송 결과가 불명확한 메시지는 재전송하지 않습니다.

검증: `tests/Test-ChatResponses.ps1`, `tests/Test-MentionSender.ps1`, `tests/Test-BotCommandBridge.ps1`.
