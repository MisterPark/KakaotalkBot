# 개인 AI 대리 응답

`개인 AI` 탭에서 일반 카카오톡 1:1 대화에 대한 대리 응답을 설정합니다. 같은 계정의 상대를 최대 10명 선택할 수 있습니다. 오픈채팅 1:1·그룹방·나와의 채팅은 선택 대상에서 제외합니다. 기존 오픈채팅 봇의 DB 수신과 개인 AI는 동시에 실행하지 않습니다.

## 사용 순서

1. 기존 `채팅` 탭의 DB 수신을 중지합니다. PC 카카오톡에 로그인하고 방 목록 읽기가 끝날 때까지 기다립니다.
2. `개인 AI` 탭에 OpenAI API 키와 사용할 모델을 입력합니다. 기본 모델은 `gpt-6.1-terra`이며 수정할 수 있습니다.
3. `내 말투·알려줘도 되는 정보`를 작성합니다. 답장할 상대를 체크하고, 목록에서 상대를 선택해 관계·평소 말투·주의할 내용을 적습니다. 예: 친구에게는 짧은 반말과 `ㅋㅋ`, 직장 동료에게는 간결한 존댓말.

   상대를 체크하면 해당 행이 선택되고 메모 입력란 제목에 상대 이름이 표시됩니다. 메모는 입력할 때마다 해당 상대의 편집 내용에 반영되며, 다른 상대를 선택했다가 돌아오면 다시 불러옵니다. 선택한 상대가 없으면 메모를 입력할 수 없습니다. 프로그램을 껐다 켜도 유지하려면 `설정 저장`을 누르세요. `미리보기 시작`·`자동응답 시작`도 설정을 저장합니다.
4. `설정 저장` 후 `연결 확인`을 누르면 가상의 인사에 대한 API 응답만 확인합니다. 이 버튼은 카카오톡 메시지를 보내지 않습니다. OpenAI API 사용료는 사용자의 API 계정에 부과됩니다.
5. `미리보기 시작` 후 상대의 **새 메시지**가 오면 답장 초안이 화면에 표시됩니다. 기존 대화에 소급해서 답하지 않습니다.
6. 결과를 확인한 뒤 `전체 중지` → `자동응답 시작`을 누르면 이후 새 메시지부터 실제 답장을 보냅니다. 처음에는 선택한 채팅창을 한 번씩 열어 DB 키를 읽을 수 있게 해 주세요.

실행 중에는 대상과 설정을 바꿀 수 없습니다. 중지 후 수정하고 다시 시작합니다. 프로그램을 다시 실행하면 자동응답은 꺼져 있으며, 응답할 상대를 다시 선택해야 합니다.

## 말투와 대화 처리

- 최근 대화 최대 80개, 전체 24,000자 범위에서 상대별 맥락과 내가 쓴 문장을 참고합니다. 식별 가능한 카카오톡 이모티콘은 팩·항목 번호로 전달합니다. 이는 모델 재학습이 아니라 매 요청의 참고자료입니다. 최근 대화 참고를 끄면 실행 이후 대화와 입력한 메모만 사용합니다.
- 선택한 상대의 대화와 해당 상대의 메모, 공통 메모만 OpenAI로 전송합니다. 다른 상대의 대화를 섞지 않습니다.
- 마지막 메시지 이후 1초간 연속 메시지를 모은 뒤 답변을 생성합니다. 자동응답은 생성된 답변 길이에 따라 8자당 약 1초(최소 1초, 최대 20초)를 기다린 뒤 보냅니다. 예: 8자 이하는 1초, 40자는 5초, 80자는 10초, 160자 이상은 20초입니다. API 답변 생성 시간과 실제 전송 작업 시간은 별도로 걸립니다. 미리보기는 생성 즉시 표시합니다.
- 작성 중이거나 전송 대기 중 새 메시지가 오면 이전 답변을 폐기하고 새 메시지를 반영합니다. 직접 답장하거나 중지하면 대기 중인 답변도 취소합니다. 예전 설정 파일의 `DelaySeconds` 값은 더 이상 사용하지 않습니다.
- 내가 직접 답장하면 해당 상대의 자동응답을 중지합니다. `선택 상대 재개`는 다음 새 메시지부터 적용됩니다. AI가 방금 전송한 답장은 내 수동 답장으로 오인하지 않도록 수신 기록과 대조합니다.
- `내 말투·알려줘도 되는 정보`와 상대별 메모는 실제 답변의 근거로 우선 사용합니다. 메모나 현재 대화에 답이 있으면 회피하거나 다시 묻지 않고 그 내용으로 직접 답합니다. 일부만 알면 아는 부분부터 답하며, 상대별 공개 제한과 최신 메모를 따릅니다. 이미 정해진 약속·일정·장소도 제공된 내용으로 설명합니다.
- 메모와 현재 대화에도 답이 없는 일상 질문이나 새로 승낙해야 하는 만남 제안에 한해서만 자연스럽게 받아넘기며 자동 답장을 이어갑니다. 모르는 사실이나 새 약속을 만들어내지 않으며, 나중에 확인하거나 연락하겠다는 약속도 임의로 하지 않습니다. 실제 금전 거래·계약 승낙·예약 확정이나 계정/인증 정보 요청은 보류합니다. 모델 판단이므로 미리보기로 실제 말투와 답변을 확인하세요.
- 답장에 AI·대리 응답 안내를 덧붙이지 않도록 지시합니다. 상대가 AI·봇·자동응답인지 물으면 그 질문만으로 보류하지 않고, 평소 반말/존댓말에 맞춰 `아니`, `아니요`처럼 짧게 부정하도록 지시합니다. 이 응답도 모델이 생성하므로 미리보기에서 확인하세요.
- 사진·음성·식별할 수 없는 이모티콘은 직접 확인하도록 중지합니다. 식별 가능한 이모티콘에는 대화 맥락에 따라 응답할 수 있습니다. 5분 넘게 지연된 메시지에는 자동으로 답하지 않습니다.
- 한 번의 답장은 최대 600자, 동시 AI 요청은 최대 2개, 실행당 요청은 최대 100회입니다. 동일 상대의 전송 결과를 확인한 뒤 다음 답장을 처리하며, 별도의 고정 15초 간격은 적용하지 않습니다. 기존 비속어 필터가 적용됩니다.
- API 오류, 초안 충돌, 불확실한 전송 결과는 자동 재시도하지 않습니다. 직접 확인 후 재개하세요. 이름이 같은 방이 여러 개면 카카오톡에서 구분되는 이름을 지정한 뒤 목록을 다시 읽어야 합니다.

## 이모티콘과 공감 선택

AI는 새 메시지와 상대별 메모를 참고해 **텍스트 답장, 카카오톡 이모티콘, 상대 메시지에 공감** 중 한 가지를 선택합니다. 직접 확인이 필요한 기존 보류 조건은 유지합니다. 미리보기에서는 선택한 행동과 이모티콘 팩·번호 또는 공감 종류를 표시하며 실제로 보내지 않습니다.

- 같은 계정에서 사용 가능한 일반·움직이는 이모티콘 중 의미 키워드가 확인되는 항목을 선택지로 전달합니다. 미니 이모티콘, 소리 항목, 만료 항목, 의미를 확인하지 못한 그림은 제외합니다.
- 보유 목록은 계정별로 전체를 읽습니다. 240개를 넘으면 최근 대화의 의미 키워드, 해당 상대에게 자주 쓴 항목, 실제 응답 조합을 우선해 이번 요청의 후보를 추립니다. 나머지 후보는 팩별로 번갈아 채웁니다. 앞쪽 400개를 자르지 않으며, 매번 전체 목록에서 최대 240개를 선정해 API로 전달합니다. 계정을 바꾸거나 새 팩을 받았으면 개인 AI를 중지 후 다시 시작해 목록을 새로 읽습니다.
- 최근 대화 참고를 켜면 상대별 최근 메시지 최대 1,000개에서 내가 자주 쓴 이모티콘, 상대가 자주 쓴 이모티콘, 상대 이모티콘 직후 15분 안에 내가 답한 이모티콘 조합을 집계합니다. 집계 결과와 최근 대화 맥락을 요청에 포함하며 다른 상대의 통계를 섞지 않습니다. 과거에 썼어도 현재 사용할 수 없는 항목은 보내지 않습니다.
- 공감은 좋아요·하트·확인·웃음·놀람·슬픔 중 하나를 선택해 답변 대상인 마지막 상대 메시지에만 적용합니다. 새로운 메시지가 도착하면 이전 대상에 대한 대기 작업을 취소합니다.
- 이모티콘과 공감은 선택 후 1초 대기하고 실행합니다. 실제 항목 탐색에는 OCR과 이미지 검색을 쓰지 않습니다. 현재 창에 연결된 카카오톡 객체에서 방·메시지·팩·항목 ID와 좌표를 읽어 확인합니다.
- 이모티콘의 전송 대기 상태는 입력칸과 별개인 채팅 로그 하단 미리보기에서 읽습니다. 선택 모델·미리보기 모델·팩·항목 번호를 대조한 뒤 한 번 전송하고 수신 DB의 본인 메시지로 확인합니다. 취소 후 남는 그림 캐시는 전송 대기로 취급하지 않습니다.
- 사용자가 작성한 내용이나 선택한 이모티콘이 있으면 자동응답을 멈춥니다. 전송 전에 작업이 취소되면 봇이 선택한 동일한 미리보기만 정리합니다. 전송 여부가 불확실하면 다시 누르지 않습니다.
- 전송 대기 내용 없이 같은 방의 이모티콘 선택창만 열려 있으면 방 연결을 검증하고 재사용합니다. 공감 선택창은 같은 방·같은 대상 메시지인 경우에 재사용합니다. 선택창이 이미 열려 있다는 이유로 전송을 중단하거나 열기 버튼을 다시 눌러 닫지 않습니다.

카카오톡 객체 구조가 바뀌어 검증에 실패하면 자동응답을 멈춥니다. 실제 메시지 전송과 공감은 `자동응답 시작`에서만 수행합니다.

## 저장과 연동

개인 AI 설정은 실행파일 옆 `PersonalAI/settings.json`에 저장합니다. API 키는 Windows DPAPI의 현재 사용자 범위로 암호화하며, 다른 Windows 계정에서는 다시 입력해야 합니다. 메모는 설정 파일에 일반 텍스트로 저장합니다. 개인 AI는 대화 기록을 Google Sheets에 쓰지 않습니다. 수신용 로컬 DB 사본은 기존 봇과 같은 `DecryptedChat` 폴더에 생성됩니다.

OpenAI Responses API에 `store: false`를 지정하고, 상대 간 서버 대화 ID를 공유하지 않습니다. 이 옵션이 API 제공자의 모든 보관 정책을 없앤다는 뜻은 아닙니다. 키와 대화 본문을 오류 로그에 기록하지 않습니다.

공식 참고: [API 시작하기](https://developers.openai.com/api/docs/quickstart), [구조화된 응답](https://developers.openai.com/api/docs/guides/structured-outputs), [기본 모델](https://developers.openai.com/api/docs/models/gpt-6.1-terra).

## 검증

### HTTP 429 안내

429는 크레딧 소진, 조직/프로젝트 지출 한도, 승인된 사용 한도, 요청 속도 제한을 각각 구분해 표시합니다. 크레딧 소진이면 [API Billing](https://platform.openai.com/settings/organization/billing)에서 **키가 속한 조직**의 잔액·충전 상태를 확인하세요. 지출/사용 한도이면 해당 조직 또는 프로젝트의 Limits를 확인하세요. 요청 속도 제한은 서버가 제공한 `Retry-After` 대기 시간이 있으면 함께 표시합니다. 자동으로 반복 요청하지 않으며, 오류 원문에 포함될 수 있는 키·조직 정보도 표시하지 않습니다. [공식 오류 안내](https://developers.openai.com/api/docs/guides/error-codes)

`tests/Test-PersonalReply.ps1`은 합성 연락처와 가짜 HTTP 응답을 사용해 키 암호화, API 형식, 오류 처리, 대화 분리, 응답 지연·취소, 수동 개입, 전송 확인을 검사합니다. 실제 OpenAI 키와 카카오톡 전송은 사용하지 않습니다. `tests/Test-ChatDatabaseReceiver.ps1`과 `tests/Test-BotCommandBridge.ps1`으로 기존 수신·명령 경로도 검증합니다.
