# 채팅창 메모리 정리

`창 정리 (24시간)`을 켜면 봇 시작 후 24시간마다 선택한 채팅창만 닫고 다시 엽니다. 카카오톡이나 봇 프로세스를 재시작하지 않으며, DB 수신과 명령 큐를 유지합니다.

- 대기 중인 명령이 있으면 정리를 미룹니다.
- 검색창과 검색 결과 컨트롤을 먼저 준비한 뒤, 채팅 입력창이 비어 있는지 다시 확인하고 닫습니다.
- 준비 실패 또는 작성 중인 내용 때문에 보류돼도 다음 정리 시도는 24시간 뒤입니다. 실패 시 1분마다 닫기를 반복하지 않습니다.
- 전송할 명령/선거 알림이 있는데 방이 닫혀 있으면 별도로 열기를 시도합니다. 실패한 열기 시도의 간격은 2분이며, 이미 열린 방은 다시 검색하지 않습니다.

메인 창이 숨겨져 있거나 최소화된 경우 복원하고, 다른 탭에서 시작하면 채팅 탭으로 이동합니다. 검색어는 전체 교체 후 일치 여부를 확인합니다. 열린 검색창에는 포커스만 지정하며 Ctrl+F를 반복하지 않습니다. 검색 결과 컨트롤을 확인하고 첫 항목을 선택한 뒤, 해당 컨트롤의 메시지 큐로만 열기 키를 보냅니다. 검색 Edit나 전역 SendKeys로 Enter를 보내지 않습니다. OCR은 사용하지 않습니다.

카카오톡의 검색 결과 컨트롤(ID 1003, `SearchListCtrl_` 이름) 구조가 바뀌거나 메뉴/대화상자 또는 사용자 입력이 감지되면 입력을 중단합니다. 최종 성공 여부는 지정한 이름의 채팅창과 카카오톡 프로세스로 확인합니다.

검증: `tests/Test-ChatRoomSearch.ps1`, `tests/Test-BotCommandBridge.ps1 -BinaryDirectory artifacts/ChatRoomStableBuild`, `tests/Test-StaInputWorker.ps1`. 실제 카카오톡 검증은 봇을 종료한 상태에서 채팅 메시지를 보내지 않는 별도 WinForms 실행기로 수행했습니다.
