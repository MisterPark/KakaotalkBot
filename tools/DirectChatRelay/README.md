# 1대1 채팅 전달 프로그램

기존 봇과 별도로 실행하는 Windows x64 / .NET Framework 4.8 프로그램입니다.
기존 복호화·DB 사본 수신 코드를 소스 링크로 재사용합니다. 기존 봇 설정과 구글 시트에는 접근하지 않습니다.

## 실행

1. `Start.ps1` 또는 `bin/Debug/DirectChatRelay.exe`를 실행합니다. 다른 PC로 옮길 때는 Debug 폴더 전체를 복사합니다.
2. 카카오톡에 로그인하고 수신할 1대1 대화와 전송할 오픈채팅방을 엽니다.
3. `DB 방 목록 읽기`를 누른 뒤 받을 1대1 방과 보낼 오픈채팅방을 선택합니다.
4. 전송방은 별도 창으로 열고 `열린 전송 창 새로고침`으로 연결합니다. DB 이름과 창 제목이 같은 창만 표시합니다.
5. `전달 시작`을 누릅니다. 수신 준비가 끝난 이후 상대방이 보낸 텍스트부터 전달합니다.

## 동작과 제한

- 본인 메시지, 시스템 메시지, 사진·파일은 제외합니다. 상대방 닉네임이 아닌 1대1 방의 상대방 ID로 판정합니다.
- 원문 그대로 보내며 긴 텍스트는 2,000자 이내로 나눕니다. 멘션은 텍스트로 전달합니다.
- DB는 읽기 사본으로 수신합니다. 복호화 사본은 exe 아래 `DecryptedChat`에 저장되며 개인 대화가 포함됩니다.
- 순차 STA 입력 작업자가 클립보드를 사용합니다. 전송 중 다른 자동 입력 봇이나 수동 입력을 함께 사용하지 마세요.
- 전송창이 없거나 작성 중인 내용이 있으면 대기합니다. 창이 닫혀 핸들이 바뀌면 중지 후 창을 다시 선택해야 합니다.
- Enter 입력 접수 횟수만 표시하며 카카오톡 서버 도착을 보장하는 수신 확인은 하지 않습니다. 전송 직후 프로세스 종료 등의 상황에 대한 정확히 한 번 전송은 보장하지 않습니다.
- 중지 시 대기 중 메시지는 폐기합니다. 재시작 시 과거 대화는 소급 전달하지 않습니다. 붙여넣기 후 중지했다면 전송방에 초안이 남을 수 있으므로 확인하세요.
- 본인 ID 자동 확인 실패 시 카카오톡의 나와의 채팅을 열고 다시 시작하세요.

## 검증

`DirectChatRelay.exe --self-test`는 실제 입력 없이 상대방·본인·방 필터, 첨부 제외와 긴 텍스트 분할을 검사합니다. 결과는 같은 폴더의 `test-result.txt`에 기록됩니다.
실제 카카오톡에서 창 연결 및 메시지 전송은 사용자 환경에서 시험이 필요합니다.
